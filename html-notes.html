HTML Notes

What is HTML?

HTML stands for HyperText Markup Language.

HTML is used to create the structure of a website.

Example:

<h1>Hello World</h1>
<p>My First Website</p>

CSS Notes

What is CSS?

CSS stands for Cascading Style Sheets.

CSS is used to design and style websites.

Example:

h1 {
    color: blue;
    font-size: 30px;
}
